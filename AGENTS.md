# Agent Workspace Rules

## Automatic README Maintenance
Whenever a file is created, added, or deleted within this repository:
1. Automatically update `README.md` to reflect the changes in the repository file structure / index.
2. Ensure new files are cataloged under their respective sections (e.g., Projects, Session Reflections) or added to a Repository Index table in `README.md`.
3. Ensure deleted files are removed from `README.md`.
